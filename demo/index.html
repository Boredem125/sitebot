Developer note. This page is a test host for the sitebot widget. In demo/index.html, replace pk_REPLACE_ME with a site's public key from the dashboard, and add localhost to that site's allowed domains. Build the widget (npm run build -w @sitebot/widget), start the API on http://localhost:8787, then open this page with npm run demo (http://localhost:4000), not as a file: the API checks the Origin header.
